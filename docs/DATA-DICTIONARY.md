# 数据定义

## 响应文件

上传单次测量的预分带响应 CSV。应用对同文件的不同频带分别计算。整个文件使用 UTF-8（含 BOM）或 GB18030，表头可重排。最多 8 MiB、100000 条表头后逻辑记录。样例为合成回归数据，带有效频带、缺点、截断、低动态范围和两段斜率。

| 字段 | 定义 |
|---|---|
| `band_hz` | 中心频率，支持 63 至 8000 Hz 的八个倍频程中心 |
| `sample_index` | 零起点整数，期望连续至 `expected_samples - 1` |
| `rate_hz` | 该预分带序列的时间基准，1000–192000 Hz |
| `expected_samples` | 声明采样数量，64–80000 |
| `unit` | 振幅单位 Pa、mPa、V 或 mV |
| `gain_db` | 仪器振幅增益，−60 至 100 dB |
| `pa_per_v` | 电压至压力校准系数，0.0001–10000 Pa/V。压力记录留空 |
| `amplitude` | 带符号、有限振幅，可用科学计数或全角字符，支持真实零值。空白或空值标记隔离 |
| `note` | 原样备注，可含换行 |

频带内校准字段须一致。重复点按规范化幅值和校准元组确认，同配置同幅值取最早物理记录，不同值整带隔离。中间缺点、尾部不足和记录超出声明长度单独报因。识别不出频带的坏行单计行勾稽。可归属的坏行先隔离其物理行，再按连续采样段评估能否缩短，避免补点或跨缺口拼接直接改变回归结果。

## 坏行、连续采样段与缩短采信

坏行（缺失/无效振幅、中间缺点、尾部截断）不再无条件整带丢弃，也禁止把断开样本直接接上（拼接会把缺失区间当成零能量衰减）。处理顺序：

1. **切段**：按 `sample_index` 把频带切成序号严格 +1 的连续采样段，段边界即缺口；每段保留首尾来源行、序号区间与点数。
2. **缺陷分级**：`CAL_CONFLICT`、`DUPLICATE_CONFLICT`、`EXTRA_POINTS` 属完整性致命缺陷，缺口两侧是否同一物理过程不可知，禁止缩短，整带退回补测。`MISSING_POINTS`、`TRUNCATED_BAND`、`ROW_ISOLATED` 属可恢复缺陷，允许在连续段上缩短估计。
3. **逐段过同一套门槛**：每段独立做校准、反向能量积分、噪声门与 T20/T30 拟合，沿用整带的全部质量门槛（尾段长度、25/35 dB 深度、最少 8 点、R²≥0.96 等）。至少一档拟合成功才记为该段可估计。
4. **同带唯一采信**：优先采信含整带直达声峰值的可估计段；否则取可用深度最大的段。其余可估计段仅留档（`EXCLUDED_RUN`），不参与回归；不可估计段记录挡下原因（如 `TAIL_TOO_SHORT`、`DYNAMIC_RANGE`）。
5. **退回补测**：所有连续段都不支撑估计时，整带判 `REMEASURE/BLOCKED`；致命缺陷带判 `REMEASURE/FATAL`。两类都不产生曲线、拟合或 RT 值。

采信段的曲线、拟合窗口、噪声与归档证据全部对账到同一采信来源行；未采信段的物理行计入 `excluded`。行勾稽互斥且守恒：输入 = 采信 + 隔离 + 重复 + 空白 + 重复表头 + 排除段。

## 信号与拟合

- 电压先按灵敏度换算至帕。增益是振幅量，除以 `10^(gain_db/20)`。时间零点为第一处绝对振幅最大点，之后按采样序号除以采样率。采样原始行号随证据保留。
- 取峰值后压力平方。用最后 15%（至少 10 点，短序列按实际点数）的五段均方中位数估计平稳噪声功率 `N`。反向累加 `p² - N` 并从后向前取非负运行最大值，得到随时间非增的剩余能量。物理初始能量等于累加值除以采样率，单位 Pa²·s。曲线使用 `10 log10(E(t)/E(0))`。能量耗尽位置为 JSON `null`。噪声底的横线是单采样噪声功率相对于起点累计能量（Pa² 样本）的 dB 读数。
- 阈值使用高于噪声 10 dB 的块平均功率。拟合范围在首次连续两个约 10 ms 的块低于阈值之前截止，并排除测噪尾段。零能量、峰后不足 40 ms 与深度不够均保留原因。T20 需要至少 25 dB 的可用深度，T30 至少 35 dB。
- 区间端点从曲线交点线性插值得到。T20 回归 −5 到 −25 dB，T30 回归 −5 到 −35 dB。内点为首个达到 −5 dB 的样本起，至首个达到下界的样本之前，至少 8 个点。最小二乘斜率须为负，R² 至少 0.96。公布值为 `RT60 = -60 / slope`，秒。屏幕显示至毫秒，勾稽比较使用未截断的数值。
- 图表为展示降低点密度，计算使用每个样本点。出具单档时保留该档，另一档给原因。两档都有时，`abs(T20-T30)/T30 > 15%` 标差，15% 的边界允许浮点计算误差。

## 频带、采样与归档

`识别频带 = 可拟合 + 动态范围不足 + 退回补测`。频带判定含采信方式 `mode`：`FULL`（整带连续采样）、`SHORTENED`（坏行断开后采信单一连续段）、`BLOCKED`（各段均不支撑估计）、`FATAL`（完整性致命缺陷）。至少一档拟合成功归可拟合（含缩短采信），否则深度不足归动态范围不足，致命缺陷或无段可采归退回补测。另对比频带身份集合与采样数量。采样行等于采信、隔离、重复、空白、重复表头与排除段之和。

验收结论 `acceptance` 单独汇总整带拟合数、缩短采信数、退回补测数与范围不足数；只要存在退回补测频带，`acceptable=false`，缩短结果不可整体验收，须补测后重算。

归档记录由源文件原字节摘要和规则版本定位。采信规则更新即提升 `RULE_VERSION`：归档批次编号随版本变化，旧版本批次的重跑以 `VERSION_CHANGED` 拒绝，原结论作废并按新规则重算；同源同版本重跑读取原始字节、重算并校验摘要一致，复用同一批次，绝不新增采信结果。运行清单含 UTC 创建时间、耗时与证据摘要。重跑读原始文件、重算并校验结果。导出保留采信与隔离、每个连续段的采信/挡下结论及来源行、校准、图表点、回归系数和窗口、噪声与勾稽结论。

当前接收完成分带的序列，未实现宽带滤波、混响室或标准的合规认证。尾段噪声按平稳模型估计，存在持续背景变化时应使用测量设备的复测结果复核。
